DSHC Field Forms - how to run
1. Quick try (Windows): double-click index.html (opens in Chrome/Edge). Everything works from the file.
2. VS Code: install the "Live Server" extension, right-click index.html > Open with Live Server.
3. Host it: upload the whole folder to GitHub Pages or your ekat.ca hosting (static files only, no server needed).
   When hosted over https, phones can "Add to Home Screen" and it works offline.

Site visit workflow (home > Start site visit)
- One form per visit. It holds C.001 FLHA, C.002 Vehicle Inspection, C.004 Daily Report, C.008 Mileage Cover Sheet,
  C.024 Worksite Inspection, C.051 Journey Management and C.052 360 Checklist, plus each fume hood inspection.
- Add each hood from the visit (customer, lab, tech carry over). Tap "Make PDFs" to get one PDF per form and per hood in a ZIP.
- Save your signature, vehicle and usual start point in Settings once; customers remember their site details.
Data is stored in each browser on each device. Use Settings > Back up everything regularly.
